# ⚽ Football Manager - Система за управление на футболни първенства

![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![Windows Forms](https://img.shields.io/badge/Windows_Forms-5C2D91?style=for-the-badge&logo=.net&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

Това е десктоп приложение (Windows Forms), разработено като годишен проект за 11. клас. Системата позволява цялостно управление на футболна организация – картотекиране на клубове и футболисти, управление на трансфери, организиране на лиги и въвеждане на резултати от мачове.

## ✨ Текущ прогрес (Етап 1 & Етап 2)

В момента проектът съдържа завършена архитектура на базата данни и напълно функциониращ модул за управление на футболни клубове.

### Функционалности
- **База данни:** Напълно проектирана релационна база данни (MySQL) с таблици за потребители, лиги, клубове, играчи, трансфери, мачове, голове и картони.
- **CRUD Клубове:** Модул за създаване, четене, редактиране и изтриване на футболни клубове през интуитивен графичен интерфейс.
- **Валидация:** Защита срещу празни полета, невалидни години на основаване и SQL Injection (чрез параметризирани заявки).
- **Сортиране и изглед:** Автоматично подреждане на клубовете по ID и стилизиран `DataGridView` за по-добро потребителско изживяване.

## 🛠 Използвани технологии
* **Език:** C# (.NET Framework)
* **Интерфейс:** Windows Forms (WinForms)
* **База данни:** MySQL (чрез XAMPP)
* **Библиотеки:** `MySql.Data` (за връзка между C# и БД)
